선택 정렬 파이썬 코드 단계별 시각화 — [5,3,8,1,4] 배열을 선택 정렬로 정렬하는 과정을 한 단계씩 확인합니다

1# 선택 정렬 (Selection Sort) — 배열: [5, 3, 8, 1, 4]
2arr = [5, 3, 8, 1, 4]
3n = len(arr) # n = 5
4
5for i in range(n - 1): # i = 0,1,2,3 (패스 횟수)
6    min_idx = i # 최솟값 위치를 i로 초기화
7    for j in range(i + 1, n): # i+1부터 끝까지 탐색
8        if arr[j] < arr[min_idx]: # 더 작은 값 발견?
9            min_idx = j # 최솟값 위치 갱신
10    # 탐색 완료! 최솟값을 맨 앞과 교환
11    arr[i], arr[min_idx] = arr[min_idx], arr[i]
12
13print("정렬 결과:", arr)
14# 출력: 정렬 결과: [1, 3, 4, 5, 8]
